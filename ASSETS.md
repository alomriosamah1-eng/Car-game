## Runtime procedural assets

Road, lane markers, curbs, trees, buildings, windows, water, and the three selectable cars are generated as Babylon meshes at runtime. No third-party asset is embedded in the game. This avoids unverified redistribution risk and keeps the bundle small.

## External research policy

The user requested GitHub research. A parallel research workflow was launched before implementation. External repositories will not be shipped unless a repository's license, redistribution terms, size and technical fit are confirmed and recorded here. The current build intentionally uses no unverified external GitHub code or asset.
